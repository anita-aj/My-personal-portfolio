# Anita Jepngetich | Personal Portfolio

A simple personal portfolio website with a dark theme and pink accents. It has five sections: Home, About, Skills, Hobbies and Contact


## Features

- Tab-style navigation using only HTML and CSS
- Highlights the active section in the nav bar
- Responsive layout for phones and desktops
- Skill and hobby chips for a quick overview
- Email link on the Contact page

## Built With

- HTML5
- CSS3
- Tailwind CSS (CDN) for the buttons
- Poppins font from Google Fonts

## Project Structure

```
index.html    - page content
style.css     - custom styles
Anita.jpeg    - profile photo
README.md
```

## Run It Locally

1. Download or clone this repository.
2. Keep `Anita.jpeg` in the same folder as `index.html`.
3. Open `index.html` in your browser.

You need an internet connection for the fonts and Tailwind.

## How the Tabs Work

Each nav link is a label connected to a hidden radio button. When a radio is checked, CSS shows the matching section and hides the rest.
